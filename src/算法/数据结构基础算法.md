# 查找
## 1. 二分查找
### 1.1 二分查找
```python
def binary_find(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right: # 查找有等号
        mid = (left + right) // 2 # 左边界
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return -1
```
### 1.2 左边界
```python
def find_left(nums, target):
    left, right = 0, len(nums) - 1
    while left < right: # 查边界没有等号
        mid = (left + right) // 2 # 左边界
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left if nums[left] == target else -1
```
### 1.3 右边界
```python
def find_right(nums, target):
    left, right = 0, len(nums) - 1
    while left < right: # 查边界没有等号
        mid = (left + right + 1) // 2 # 右边界+1
        if nums[mid] > target:
            right = mid - 1
        else:
            left = mid
    return left if nums[left] == target else -1
```
# 排序
## 1.快速排序
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr)//2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```
## 2.归并排序
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    res = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            res.append(left[i])
            i += 1
        else:
            res.append(right[j])
            j += 1
    res.extend(left[i:])
    res.extend(right[j:])
    return res
```

## 2.bisect（二分查找）
用bisect写二分查找函数
```python
import bisect
 
def search(a, x):
    i = bisect.bisect_left(a, x)
    if i != len(a) and a[i] == x:
        return i
    return None
```
bisect模块主要以下几个函数 
1. bisect(a,x)函数：返回x将会插入列表的位置，但不会插入
2. bisect_left(a,x)函数，返回x将会插入列表a的位置，如果有相同元素的话，返回插入左边的位置，但不会插入
3. bisect_right(a,x)函数，返回x将会插入列表a的位置，如果有相同元素的话，返回插入右边的位置，但不会插入
4. insort(a, x)函数，把变量x插入到列表a中，并能保持a的顺序。
5. insort_left(a, x)，在列表a中插入元素x，并能保持a的顺序。如果x已经在a中，把它插入x的左边。
6. insort_right(a, x)，在列表a中插入元素x，并能保持a的顺序。如果x已经在a中，把它插入x的左边。
